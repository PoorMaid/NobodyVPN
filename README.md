# NobodyVPN

一款免费、简洁的 Android 代理工具。

## 特点

- 免费使用，无广告
- 节点订阅内置，打开即用，无需手动配置
- 一键完成：拉取订阅 → 解析节点 → 去重合并 → 批量测速 → 自动连接最优节点
- 节点池自动维护：新节点自动收录，连续测试失败的节点自动清理
- 服务器列表页可查看节点名称与延迟，支持一键测速和手动切换
- 支持分应用代理，可自选哪些应用走代理
- 界面极简，只保留连接所需的最少功能

## 使用说明

1. 打开 App，进入连接页
2. 点击中央大圆按钮，App 自动拉取订阅、解析节点、测速并连接最优节点
3. 连接成功后按钮显示绿色对勾；再次点击即可断开
4. 在服务器列表页可查看全部节点与延迟，点右上角可重新测速，点节点可手动切换
5. 在分应用代理页可选择哪些应用走代理
