# NobodyVPN

一款免费、简洁的 Android 代理工具。

## 特点

- 免费使用，无广告
- 订阅导入后自动解析节点、去重、测速
- 一键连接最优节点
- 支持分应用代理
- 节点池自动维护：新节点自动收录，失效节点连续失败后自动清理
- 界面极简，只保留连接所需的最少功能

## 下载

[GitHub Releases](https://github.com/PoorMaid/NobodyVPN/releases)

最新版本：v1.4.6

## 使用说明

1. 首次打开 App，在订阅页填入订阅链接
2. 点击中央大圆按钮，自动解析、测速、连接最优节点
3. 再次点击按钮可断开连接
4. 分应用代理页可选择哪些应用走代理
